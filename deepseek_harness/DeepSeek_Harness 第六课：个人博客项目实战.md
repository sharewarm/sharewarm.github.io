# 使用 DeepSeek Harness 开发个人博客网站

## 一、项目介绍

本项目将使用 DeepSeek Harness（简称 DSH）辅助开发一个个人博客网站。

网站完成后，访客可以浏览文章列表、查看文章详情；管理员可以进入后台，发布、编辑和删除文章。文章数据保存在 SQLite 数据库中。

### 1.1 功能清单

**博客前台**
- 展示博客首页和文章列表
- 展示文章标题、发布时间、摘要
- 点击文章进入详情页
- 提供简单的导航和页面样式

**博客后台**
- 进入文章管理页面
- 新增文章
- 编辑已有文章
- 删除文章

**数据与运行**
- 使用 Flask 提供后端服务
- 使用 SQLite 保存文章数据
- 提供基本的输入校验和错误提示
- 能在本地启动并验证主要功能

### 1.2 技术组成

| 技术 | 用途 |
|---|---|
| HTML | 页面结构 |
| CSS | 页面样式 |
| JavaScript | 页面中的必要交互 |
| Python | 后端逻辑 |
| Flask | 处理网页请求 |
| SQLite | 保存文章数据 |
| pytest | 编写和运行基础测试 |

## 二、项目准备

### 2.1 检查开发环境

开始前，请确认电脑已经安装：
- Python 3.10 或更高版本
- DSH 及其所需运行环境
- 能够运行终端命令的环境

DSH 的启动方式、工作目录和权限设置沿用已有的 DSH 安装与使用指南。本项目不重复介绍安装过程。

### 2.2 创建项目目录

先创建一个项目文件夹，例如：

```text
personal_blog/
```

在 DSH 中打开或进入这个项目目录。后续生成的代码、配置文件和测试文件都应保存在该目录内。

### 2.3 让 DSH 先检查项目环境

不要一开始就要求 DSH 一次性生成整个网站。先让它查看当前目录和运行环境，确认实际情况。

**在 DSH 中输入：**

```text
请检查当前项目目录和 Python 环境：
1. 列出当前目录中的文件和子目录；
2. 检查 Python 版本；
3. 检查 Flask、pytest 是否已安装；
4. 如果目录中已有文件，请先说明它们的作用，不要覆盖或删除；
5. 暂时不要编写项目代码。
请把检查结果和下一步建议告诉我。
```

根据检查结果继续。如果缺少依赖，让 DSH 给出安装命令；执行前先检查命令内容，确认无误后再运行。

## 七、使用 SQLite 保存文章

- 正文

## 十二、项目完成后的练习

完成基础项目后，可以逐项扩展。每次只增加一个功能，并先让 DSH 给出修改方案。

### 练习一：文章搜索

为首页增加搜索框，支持按文章标题查找。

### 练习二：文章分类

为文章添加分类字段，并在前台按分类筛选。

### 练习三：分页

当文章数量增加时，将文章列表拆分为多个页面。

### 练习四：Markdown 正文

允许使用 Markdown 编写文章，并在详情页展示格式化后的正文。需要特别注意对渲染内容进行安全处理。

### 练习五：后台身份验证

为后台增加登录验证，并检查未登录用户是否能够访问管理页面。完成身份验证与安全检查后，才考虑部署到可被其他人访问的环境。

## 十三、使用 DSH 开发时的基本工作方式

开发过程中，每次只提出范围明确的任务。一个阶段完成后，先检查实际文件和运行结果，再继续下一阶段。

遇到问题时，向 DSH 提供：
- 你执行了什么操作；
- 你预期出现什么结果；
- 实际出现了什么结果；
- 完整报错信息；
- 相关文件内容（必要时）。

不要只说“程序有问题，帮我修复”。尽量要求 DSH 先定位原因、说明修改范围，再进行修复。

对涉及删除文件、覆盖已有代码、修改数据库或执行系统命令的操作，先检查具体内容并确认后再执行。DSH 的实际文件操作和命令执行能力取决于当前运行环境、启用的工具及权限设置。
