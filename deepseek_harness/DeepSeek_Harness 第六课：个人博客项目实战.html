使用 DeepSeek Harness 开发个人博客网站

一、项目介绍

本项目将使用 DeepSeek Harness（简称 DSH）辅助开发一个个人博客网站。

网站完成后，访客可以浏览文章列表、查看文章详情；管理员可以进入后台，发布、编辑和删除文章。文章数据保存在 SQLite 数据库中。

1.1 功能清单

博客前台 - 展示博客首页和文章列表 - 展示文章标题、发布时间、摘要 - 点击文章进入详情页 - 提供简单的导航和页面样式

博客后台 - 进入文章管理页面 - 新增文章 - 编辑已有文章 - 删除文章

数据与运行 - 使用 Flask 提供后端服务 - 使用 SQLite 保存文章数据 - 提供基本的输入校验和错误提示 - 能在本地启动并验证主要功能

1.2 技术组成

技术 用途
HTML 页面结构
CSS 页面样式
JavaScript 页面中的必要交互
Python 后端逻辑
Flask 处理网页请求
SQLite 保存文章数据
pytest 编写和运行基础测试

十三、使用 DSH 开发时的基本工作方式

开发过程中，每次只提出范围明确的任务。一个阶段完成后，先检查实际文件和运行结果，再继续下一阶段。

遇到问题时，向 DSH 提供： - 你执行了什么操作； - 你预期出现什么结果； - 实际出现了什么结果； - 完整报错信息； - 相关文件内容（必要时）。

不要只说“程序有问题，帮我修复”。尽量要求 DSH 先定位原因、说明修改范围，再进行修复。

对涉及删除文件、覆盖已有代码、修改数据库或执行系统命令的操作，先检查具体内容并确认后再执行。DSH 的实际文件操作和命令执行能力取决于当前运行环境、启用的工具及权限设置。
